# 隐私与失败状态

文章只保存到项目下的 `article-library/`。读取器使用独立的 `.wechat-reader-profile/` Edge 配置目录，不读取默认浏览器资料、剪贴板、凭据或微信进程，也不会把文章上传到第三方。

只接受 `https://mp.weixin.qq.com/` 下的非根路径。工具不会绕过访问限制，不会注入微信，也不会根据标题或摘要猜测缺失正文。

状态含义：

- `complete`：正文非空且标题、正文均已提取。
- `partial`：正文已提取但缺少标题等元数据。
- `empty`：页面没有可读取的正文。
- `restricted`：页面要求登录、验证码或拒绝正常访问。
- `timeout`：页面在限定时间内未加载完成。
- `failed`：发生其他采集或保存错误。

当文章受限时，Codex 会明确告诉你无法读取；不会伪造文章内容。原始 HTML 仅作为受限文本证据保存，不能被当作脚本执行。

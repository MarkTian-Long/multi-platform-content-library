# 隐私与失败状态

## 多平台链接资料库

新入口是项目根 `启动链接资料库.cmd`，接受用户主动粘贴的 HTTP(S) 链接和分享文案。新资料保存在 `资料库/`；平台专用浏览器资料在 `程序文件/.content-profile/`，B 站专用 Cookie 文件只保存在该目录。原始资料、转写和 OCR 默认在本机处理，不自动上传云端，也不监听剪贴板。

本地队列、正文底稿、资料清单可能保存短链或平台访问所需参数，不能直接公开整个资料库。对外分享请使用“导出资料包”；CLI、MCP 和阅读页统一隐藏常见令牌及签名参数，导出不包含原始网页/下载器信息文件、浏览器会话和 Cookie。该处理不等于匿名化正文里的姓名等个人信息。

普通 HTTP 下载拒绝本机、私网地址和凭据 URL；每次跳转重新校验，公网 DNS 结果固定到下载连接。正文、文件、索引和子进程均有大小或时间上限。专用浏览器只能采集正常可见页面，不解决付费、加密或访问权限限制。

新任务区分 `queued/running/paused/completed/partial/failed/cancelled/login_required`，每个文件另行记录状态、哈希和来源。`partial` 可以表示文件未取得，也可以表示视频时长、评论或弹幕覆盖范围未知。取消或失败保留已完成文件；中断任务可继续，Windows 文件短暂占用会有界重试，不会先删除上一份有效清单。

完整操作、上限和实际验证边界见 [操作手册](link-library-manual.md) 和 [验收报告](link-library-acceptance.md)。

## 原微信公众号兼容入口

文章保存到项目下的 `文章库/`；为兼容已有记录，旧的 `article-library/` 仅在首用时复制迁移，不会自动删除。读取器使用独立的 `.wechat-reader-profile/` Edge 配置目录，不读取默认浏览器资料、剪贴板、凭据或微信进程，也不会把文章上传到第三方。

只接受 `https://mp.weixin.qq.com/` 下的非根路径。工具不会绕过访问限制，不会注入微信，也不会根据标题或摘要猜测缺失正文。

状态含义：

- `complete`：正文非空且标题、正文均已提取。
- `partial`：正文已提取但缺少标题等元数据。
- `empty`：页面没有可读取的正文。
- `restricted`：页面要求登录、验证码或拒绝正常访问。
- `timeout`：页面在限定时间内未加载完成。
- `failed`：发生其他采集或保存错误。

当文章受限时，Codex 会明确告诉你无法读取；不会伪造文章内容。原始 HTML 仅作为受限文本证据保存，不能被当作脚本执行。文章图片仅在页面提供真实 HTTP(S) 图片地址、且下载符合类型与大小限制时保存为本地文件；下载失败会如实记录，不影响已提取的正文。

视频会按正文中的位置识别；可正常获取的微信/腾讯视频直链保存到文章目录的 `videos/`。每篇最多下载 20 段，单段不超过 100 MB，总计不超过 500 MB，同时最多下载 2 段。登录限制、验证码、加密或分段流不在下载支持范围内；下载失败或超过限制会保留原文入口，窗口报告实际保存数。

原生播放器可能在初始地址失败后正常切换到另一个播放地址。采集最多等待 15 秒让这一过程完成，再提取当前地址；不会自行修改签名、调用私有接口或导入登录凭据。永久失败或懒加载媒体不会无限阻塞正文保存。HTTP 206 只有明确覆盖整份文件才能保存；对未编码的响应还会核对实际字节数与声明长度，避免把不完整片段标成成功。

Markdown 链接到本地视频文件，PDF 用静态说明和原文入口表示视频。PDF 生成不运行原始页面的脚本，也不加载远程播放器。视频的临时签名播放地址不进入文章索引、Markdown 或错误日志；原始网页证据 `source.html` 可能包含网页当时的临时地址，不宜对外分享。

窗口在独立进程中运行读取程序，在界面线程上检查进度；支持 Windows PowerShell 5.1。读取错误会保留可识别的错误码和中文解释，不把正文保存成功但 PDF 或媒体失败说成全部成功。“取消读取”只停止本窗口当前任务及其子进程，已经保存的文件保留。强制中断可能留下临时目录，该目录不代表一篇成功保存的文章。

错误日志保存在 `程序文件/logs/reader.log`；内容只用于本地排错，链接会被省略。单份日志超过约 1 MB 时轮换，最多保留当前和上一份。删除日志不影响文章库。

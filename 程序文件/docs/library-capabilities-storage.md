## 路径与保留规则

| 路径（项目根为 `D:\开发\多平台资料库`） | 用途 | 回收规则 |
| --- | --- | --- |
| `资料库/items/平台 - 标题 [短ID]/` | 正式原件、综合正文、字幕/识别数据、阅读 HTML/PDF、版本 | 保留；人类可读命名与内部 ID 分离 |
| `资料库/staging/` | 采集、处理、崩溃恢复的工作文件 | 只回收终态中已被正式资产完整覆盖的副本；未知/差异/中断/receipt 保留 |
| `资料库/exports/` | 用户主动生成的交付副本 | 不自动删除；不作为正式主版本 |
| `资料库/.organization/items.json`、`资料库/history/` | 标签收藏、任务恢复快照 | 原清单独立保存；私有恢复输入不进入公开搜索结果或导出包 |
| `资料库/items/.../校订历史/` | 稳定用户稿和版本来源记录 | 机器/平台原稿保持；新校订与旧稿分别保存，当前稿保持可读入口 |
| `资料库/.命名备份`、`.平台识别备份` | 可核验的迁移与识别恢复材料 | 保留，不按目录名推定无用 |
| `文章库/` | 旧公众号采集器兼容数据 | 当前仍被使用，保留；本轮不做重复迁移 |
| `程序文件/src`、`dist`、`scripts` | 开发源码、构建程序、运行辅助脚本 | 保留运行入口；按任务的诊断脚本放在 logs，不进入生产脚本目录 |
| `程序文件/tools`、`.venv-content`、`node_modules` | 本机依赖和 Small/Tiny 离线模型 | 保留已安装组件、模型及许可证；安装包/重复解压组件仅在校验后回收 |
| `程序文件/.content-profile`、`.wechat-reader-profile` | 应用专用会话 | 保留账号/登录状态；未读取默认浏览器，也未清理这些目录 |
| `程序文件/logs/` | 小型验证报告、复现实例、截图 | 本轮回收与正式资产 SHA 相同的大副本，保留足够证据；新增实验结束清理自己的大夹具 |
| `程序文件/.log-archives/` | 已核验日志ZIP及恢复清单 | 内部恢复材料；源码/公开资料包排除；恢复遇到新材料不覆盖 |
| `程序文件/logs/drafts/` | 保存失败时的校订草稿 | 保留为用户未完成工作，禁止当可重建日志归档或回收；成功保存后只删除该草稿 |
| `版本备份/` | 源码、入口、测试和文档的可恢复ZIP | 逐文件回读SHA验证；排除资料、登录信息、模型、依赖及运行记录 |

默认路径适合当前 D 盘项目，无需为这次工作迁移到 C 盘或新工作树。`CONTENT_LIBRARY_ROOT` 可指向已有的绝对目录；切换前需连同 items、queue、staging 和恢复映射整体核验，不能只移动一个视频或阅读页。当前路径没有被移动。

## 用户截图中的启动故障与修复

用户实际双击时，CMD 把 `%~dp0` 得到的末尾反斜杠直接放进带引号的 `-ProjectRoot` 参数。回归测试在含中文、空格和括号的目录中复现：PowerShell 实际收到的根路径以字面引号结尾，`GetFullPath()` 报“路径包含非法字符”。窗口随后继续初始化，使用损坏的路径查询后端，造成“缺少 dist\\link-cli.js”的连锁误报；磁盘中的构建文件实际存在。

修复后窗口默认从 `$PSScriptRoot` 推导项目位置，CMD 不再传递根路径；独立启动隐藏的 PowerShell 控制台并立即结束 CMD。路径初始化失败时停止启动，把错误写入脚本目录下的 `logs/link-window.log`，正常窗口模式显示启动失败对话框。

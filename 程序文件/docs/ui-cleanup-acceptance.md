# 目录与界面整理验收

日期：2026-09-19。Luna 整理启动入口及文档，Terra 实现界面分区和任务行为，主代理负责补充实现、回归与截图验收。

## 结果

- 根目录仅保留 `启动多平台资料库.cmd`；旧入口移入 `程序文件/legacy/`，仍可定位项目根。
- 默认打开资料库，采集任务、登录与依赖各有独立页面。资料与任务采用两行条目，标题与中文状态、平台、日期分开。
- 当前任务默认排除已结束记录；“查看历史”显示全部记录，切换立即生效，最新任务优先。
- “保存链接”完成入队并启动；“仅加入队列”暂存；成功入队清空输入，有待处理任务时可“继续队列”。
- 修复启动任务请求占用进程槽导致资料库未加载，以及后台结束后刷新未完整执行的问题。
- 失败入队不会遗留自动启动标记；后台失败仍触发刷新；过期的资料详情结果不会覆盖新选择。
- 缺少 PDF、视频路径时禁用对应入口，历史已完成任务不能取消。

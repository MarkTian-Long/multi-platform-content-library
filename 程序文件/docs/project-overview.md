# 多平台资料库

当前功能入口见[操作手册](link-library-manual.md)，平台/文件类型与真实限制见[支持表](platform-support.md)，最新实施、独立复核、数据保护和会话收尾见[升级验收](plans/2026-10-14-library-usability-upgrade.md)。新增处理选择、文字稿/OCR校订、PDF/DOCX/原图、标签收藏、ZIP和可恢复任务/日志归档均沿用同一文件库。

多平台资料库是一个 Windows 本地应用：把用户主动提交的公开链接、分享文案或明确选择的本地文件保存成可离线阅读、可搜索、可追溯的资料。它保存已经能够取得的内容，不尝试绕过登录、付费、验证码、DRM 或平台访问限制。

## 日常流程

```text
采集任务：粘贴链接 → 保存链接 → 查看任务状态
                                  ↓
                     缺少工具 / 需要登录时处理
                                  ↓
资料库：搜索、阅读、打开媒体或导出资料包
```

“登录与依赖”不是另一个采集入口。任务显示“缺少工具”时，先检查并安装本机工具；显示“需要登录”时，选择对应平台并在专用浏览器登录，然后回到采集任务重试。

## 支持范围

| 来源 | 可处理范围 | 已知边界 |
| --- | --- | --- |
| 微信公众号 | 正文、可取得图片、可正常下载的视频、离线页和 PDF | 受限、过期、分段流或超限视频会保留来源而不伪报下载成功 |
| 微信视频号 | 分享链接、公开直链视频和可配置第三方解析 | sph 短链已有免登录解析下载验证；服务可用性及内容权限影响结果，加密媒体不解密 |
| B 站 | 公开视频/多P、可用字幕/评论/弹幕和派生产物，动态/opus图文及关联BV引用 | 可能需要登录，按实际任务结果判断；动态关联视频需另行提交BV |
| 小红书 | 可访问笔记正文和媒体 | 登录、验证码和页面变化会影响结果 |
| YouTube | 明确单视频的说明、核验MP4和本地ASR/OCR | 真实下载/完整解码/入库/转写已验收；429持久冷却和窗口有限恢复，验证由用户完成；不含直播、播放列表、原生字幕/评论、DRM/分段流 |
| 抖音 | 精确单作品说明、核验 MP4、后续 ASR / OCR | HTTP → 专用 Edge → yt-dlp；真实公开样本已匿名下载并核验。图文图片/主页/合集/直播未开放 |
| 微博 | 单帖原文/图片/MP4，TV仅目标视频，后续 ASR / OCR | MID/BID归一、长文完整性与转发隔离；官方接口失败后自动 Edge，真实单视频帖桌面/移动入口均已匿名下载 |
| 本地文件 | TXT/Markdown/静态HTML、文字层PDF、DOCX、PNG/JPEG/WebP/BMP、支持的音视频原件及派生产物 | 原件只复制、身份含格式/SHA，检查源文件变化；扫描PDF OCR、EPUB、加密/宏等主动内容未开放 |
| 普通网页 | 可读取正文、图片及页面公开提供的资源 | 站点结构和媒体授权决定可保存范围 |

公开网页、微信公众号、公开 B 站视频、小红书和微信视频号各一个视频样本已有实际保存验证。视频号原视频通过当前免费解析服务取得，并通过整段音视频解码检查；其他图集、登录态和 B 站多 P 的真实链接覆盖仍在扩充，不能据此推断所有链接都可下载。

详细输入域名、格式、视频号设置与实测条件见 [平台与格式支持表](platform-support.md)。普通网页目前提取正文和图片，不具备任意站点视频下载器。

本地文件可从“资料库”导入并使用同一队列。成功入库的原件可支撑源文件移动后的派生重试；队列结束会核验并回收终态 staging 中已经被正式资产完整覆盖的副本。默认主库继续为项目下 `资料库/`，工具/模型留在 `程序文件/`，兼容文章区和恢复备份保留；完整功能、路径和实际回收见 [功能与存储说明](library-capabilities-storage.md)。

## 本地数据与隐私

- `资料库/`：新的多平台资料及派生产物。
- `文章库/`：原微信采集兼容存储；不会在整理或重试时被删除。
- `程序文件/`：程序、离线工具、模型、日志和文档。

目录、GitHub排除、清理和恢复规则见[目录规范](directory-conventions.md)。首次下载需在程序目录`npm ci`并构建；源码不含本机配置、账号或模型。

资料、转写和 OCR 默认在本机处理；应用不读取默认浏览器资料、不监听剪贴板，也不调用云端 AI API。平台登录只使用应用专用浏览器资料。

启用视频号第三方解析时，仅将主动提交的 sph 分享链接发给配置的解析站，不附加平台 Cookie 或登录信息。当前内置服务不需要调用者的服务凭证；视频下载、阅读资料与派生产物保存在本机。

```powershell
cmd /c npm run typecheck
node dist/link-cli.js doctor
```

# 多平台资料库

Windows本地资料收集应用：把主动提交的链接和选定的本地文件保存为可离线阅读、搜索、校订和导出的资料。原件、机器识别稿和人工校订版本分别保留。

## 首次安装

需要Windows、Microsoft Edge、Windows PowerShell 5.1和Node.js 22.13.0及以上，当前验收使用Node.js 24。语音转写另需Python和离线模型，可由应用工具安装入口准备。

克隆或下载源码后，在项目根打开终端：

```powershell
cd 程序文件
cmd /c npm ci
cmd /c npm run build
```

完成后双击唯一日常入口[启动多平台资料库.cmd](启动多平台资料库.cmd)。启动器打开独立功能窗口后关闭黑框，关闭启动黑框不结束功能窗口。缺少工具时在“登录与依赖”点击“安装到应用目录”；工具和模型准备需要网络，已准备的转写与OCR在本机执行。

## 日常使用

1. 在“采集任务”粘贴链接，选择原件、原件+文字稿或完整处理，点击“保存链接”。窗口默认原件+文字稿；完整处理增加视频关键帧和图片识别，CLI/MCP未给选项及旧任务保持完整处理。
2. 用“结果详情”查看已保存项、缺失原因和操作，直接打开或校订文字稿。机器/平台原稿独立保留，校订历史可恢复，已有阅读PDF随校订更新。
3. 在“资料库”搜索正文与标签，筛选平台/收藏，打开离线页、媒体、文字稿和PDF，导出目录包或经核验ZIP。
4. 导入文字、HTML、文字层PDF、DOCX、图片和音视频。原件只复制，原图可离线OCR，视频可本地转写。
5. 已完成/取消任务可归档并恢复，资料继续保留；失败和部分保存任务可重试。工作副本及旧日志先核验归属与恢复条件再清理。

## 平台和格式

| 来源 | 当前主要范围 |
| --- | --- |
| 微信公众号 | 正文、图片、可取得的文章内视频 |
| 微信视频号 | 分享链接、可取得视频，可选第三方分享链接解析 |
| 小红书 | 笔记正文、图片、视频、短链与专用Edge |
| B站 | BV/b23视频、可用字幕/评论/弹幕、多P、动态图文及关联BV引用 |
| 抖音 | 单视频作品、分享短链、专用Edge回退 |
| 微博 | 单帖/移动入口/TV/短链、原文/图片/目标视频 |
| YouTube | 明确单视频的标题、说明、核验MP4与本地派生资料 |
| 普通网页 | 可读取正文与图片 |
| 本地文件 | TXT/MD/HTML、文字层PDF、DOCX、PNG/JPEG/WebP/BMP、MP4/MOV/WebM/MKV、M4A/MP3/WAV/AAC/FLAC/OGG |

具体链接/格式和边界见[平台与格式支持表](程序文件/docs/platform-support.md)。登录、验证码、付费、过期地址及平台限制会影响产物；扫描PDF OCR、EPUB、任意网页视频、YouTube播放列表/直播/原生字幕评论等尚未开放。

YouTube提供自动/直连/本机代理设置与专用浏览器验证。429默认冷却5、15、30分钟，最多自动恢复三次；有效Retry-After更长时遵守服务器要求。功能窗口打开时到期自动继续，关闭后保留等待记录，重开续接；连续限流或平台验证会转人工处理。其他平台继续运行，已有资料保留。

视频号第三方解析默认关闭；启用后只发送主动提交的分享链接，不附加平台Cookie/账号信息。媒体和识别产物保存在本机。新clone不会继承已有机器的代理选择、登录或模型；公开样本成功不代表所有链接持续可访问。

## 目录与维护

| 路径 | 用途 | GitHub同步 |
| --- | --- | --- |
| 根README、CHANGELOG和日常启动器 | 安装、使用与版本入口 | 是 |
| 程序文件的源码/脚本/测试/文档/依赖清单 | 程序与维护材料 | 是 |
| 资料库、文章库 | 正式资料、队列/组织/校订/历史、微信兼容存储 | 否 |
| 程序文件中的依赖/构建/工具/模型/日志/专用账号/本地配置 | 本机运行材料 | 否 |
| 版本备份 | 带哈希清单的本地源码恢复ZIP | 否 |

完整规则见[目录规范](程序文件/docs/directory-conventions.md)，实际清理见[清理记录](程序文件/docs/workspace-cleanup.md)。旧微信入口在`程序文件/legacy/启动公众号文章阅读器.cmd`，继续读取原文章库。

维护和检查见[开发说明](程序文件/README.md)，MCP注册见[MCP配置](程序文件/docs/mcp-setup.md)，操作见[手册](程序文件/docs/link-library-manual.md)。应用不导入默认浏览器资料、不监听剪贴板，也不调用云端AI API。GitHub源码同步不等于用户资料备份。

2026-10-14版本通过579项回归、类型检查和构建，以及43项限定独立复验；到期恢复经过模拟等待记录和真实公开视频下载/完整解码验证。版本内容见[CHANGELOG](CHANGELOG.md)，详细结果见[升级验收](程序文件/docs/plans/2026-10-14-library-usability-upgrade.md)。原日志回执仅留本机，源码包含脱敏说明和可重跑测试。

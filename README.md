# 多平台资料库

[中文](README.md) | [English](README.en.md)

Windows本地资料收集应用：把主动提交的链接和选定的本地文件保存为可离线阅读、搜索、校订和导出的资料。原件、机器识别稿和人工校订版本分别保留。

## 首次安装

需要Windows、Microsoft Edge、Windows PowerShell 5.1和Node.js 22.13.0及以上，当前验收使用Node.js 24。语音转写另需Python和离线模型，可由应用工具安装入口准备。

克隆或下载源码后，在项目根打开终端：

```powershell
cd 程序文件
cmd /c npm ci
cmd /c npm run build
```

完成后双击[多平台资料库.exe](多平台资料库.exe)，直接打开资料库界面，无需保留终端窗口。构建会自动生成此入口；旧`启动多平台资料库.cmd`继续兼容，但CMD自身仍可能显示或闪现终端，日常请使用EXE。退出应用请关闭资料库窗口。缺少工具时在“登录与依赖”点击“安装到应用目录”；工具和模型准备需要网络，已准备的转写与OCR在本机执行。

## 日常使用

1. 在“采集任务”粘贴链接，选择原件、原件+文字稿或完整处理，点击“保存链接”。窗口默认原件+文字稿；完整处理增加视频关键帧和图片识别，CLI/MCP未给选项及旧任务保持完整处理。
2. 选中资料后，“打开阅读页”查看离线排版，“打开文字稿”打开整篇文章正文或完整文字稿，“打开 PDF”打开同一条目的当前PDF。“打开目录”进入这条资料所在文件夹。
3. 在“资料库”搜索正文与标签，筛选平台/收藏。“管理资料 ▾”提供结果详情、标签与收藏、补充缺项和“校订识别稿 / 转写稿”；图片OCR、音视频转写及其校订版本独立保留。“导出 ▾”提供资料包文件夹和经核验ZIP，副本保存在`资料库/exports`。
4. 导入文字、HTML、文字层PDF、DOCX、图片和音视频。原件只复制，原图可离线OCR，视频可本地转写。
5. 已完成/取消任务可归档并恢复，资料继续保留；失败和部分保存任务可重试。工作副本及旧日志先核验归属与恢复条件再清理。

公众号原始页面已保存时，离线阅读页和PDF保留原文正文、图片及主要排版；OCR等处理稿作为辅助材料单独访问。原文排版与真实样本验证见[阅读保真验收](程序文件/docs/reviews/2026-10-21-wechat-reading-fidelity.md)。

## 平台和格式

| 来源 | 当前主要范围 |
| --- | --- |
| 微信公众号 | 正文、图片、可取得的文章内视频 |
| 微信视频号 | 分享链接、可取得视频，可选第三方分享链接解析 |
| 小红书 | 笔记正文、图片、视频、短链与专用Edge；实况原对象图片、配套动态及画质选择 |
| B站 | BV/b23视频、可用字幕/评论/弹幕、多P、动态图文及关联BV引用 |
| 抖音 | 单视频、静态/实况图集、分享短链；图集按水印证据、尺寸与码率选择版本 |
| 微博 | 单帖/移动入口/TV/短链、原文/图片/目标视频；实况照片原图及配套MOV/MP4 |
| YouTube | 明确单视频的标题、说明、核验MP4与本地派生资料 |
| 普通网页 | 可读取正文与图片 |
| 本地文件 | TXT/MD/HTML、文字层PDF、DOCX、PNG/JPEG/WebP/BMP、MP4/MOV/WebM/MKV、M4A/MP3/WAV/AAC/FLAC/OGG |

具体链接/格式和边界见[平台与格式支持表](程序文件/docs/platform-support.md)。登录、验证码、付费、过期地址及平台限制会影响产物；扫描PDF OCR、EPUB、任意网页视频、YouTube播放列表/直播/原生字幕评论等尚未开放。

小红书、抖音和微博的实况照片分别保存图片与对应动态视频，阅读页标明原照片序号并可离线播放；已声明却缺失、受保护或核验失败的动态会显示部分保存，已取得的图片保留。

小红书可根据同一照片明确提供的资源身份取得原对象，保持JPEG/WebP/HEIC/HEIF等实际格式；HEIC/HEIF另保留平台网页预览。抖音图集优先平台标记无水印的版本，比较来源尺寸和码率，避免优先选择带水印的下载模板。文件不转码，阅读页显示实测尺寸、原对象/平台版本/网页预览及水印依据，重试保留同资源较高画质原件、复用已核验预览。实测小红书图片从1080×1440网页图取得3024×4032 HEIC；抖音图片达到接口声明尺寸，动态样本仅提供720×960且标记无水印。小红书该样本动态仍有水印；无来源证据时明确显示未知，不承诺所有链接能取得作者上传母版或无水印版本。详见[画质与水印验收](程序文件/docs/reviews/2026-10-14-original-media-quality.md)。

GIF保留原字节；PDF是静态阅读副本。手机相册的原生Live Photo复合文件导入尚未提供，初次图集范围见[图集验收](程序文件/docs/reviews/2026-10-14-photo-collections.md)。

YouTube提供自动/直连/本机代理设置与专用浏览器验证。429默认冷却5、15、30分钟，最多自动恢复三次；有效Retry-After更长时遵守服务器要求。功能窗口打开时到期自动继续，关闭后保留等待记录，重开续接；连续限流或平台验证会转人工处理。其他平台继续运行，已有资料保留。

视频号第三方解析默认关闭；启用后只发送主动提交的分享链接，不附加平台Cookie/账号信息。媒体和识别产物保存在本机。新clone不会继承已有机器的代理选择、登录或模型；公开样本成功不代表所有链接持续可访问。

## 目录与维护

| 路径 | 用途 | GitHub同步 |
| --- | --- | --- |
| 根目录中英README、CHANGELOG、兼容CMD和程序文件内的启动器源码 | 安装、使用与版本入口 | 是 |
| 程序文件的源码/脚本/测试/文档/依赖清单 | 程序与维护材料 | 是 |
| 资料库 | 唯一日常资料库，以及队列、标签收藏、校订和历史 | 否 |
| 程序文件中的依赖/构建/工具/模型/日志/专用账号/本地配置、根EXE | 本机运行材料，由构建和工具准备生成 | 否 |
| 版本备份 | 带哈希清单的完整资料/源码恢复ZIP与快速回退材料 | 否 |

正式资料统一在`资料库/items/`，条目目录采用`YYYY-MM-DD_平台_标题`；日期取原采集时间在北京时间对应的日期，同名时追加序号，稳定ID保存在清单中。条目根的`文章标题.md`、`文章标题.html`、`文章标题.pdf`分别对应全文、离线阅读页和当前PDF，PDF在已生成时提供。图片、视频等原件直接进入各自类型目录，处理结果、历史版本和`.内部`保留必要边界。项目树和恢复方式见[存储目录说明](程序文件/docs/storage-layout.md)。

旧`文章库`的归档位置为`版本备份/单库整理-20261021/旧文章库`，整理前完整备份也在这次备份目录中；它用于恢复，不再作为第二个日常库。新构建的微信兼容接口共用正式资料库：已有配置显式指向同项目`文章库`时，凭正式库布局标记解析到`资料库`，归档旧目录后仍可使用旧文章ID。独立自定义旧库保持原配置的兼容行为。已加载旧代码的MCP进程需要重启才能使用新逻辑。

完整规则见[目录规范](程序文件/docs/directory-conventions.md)，实际清理见[清理记录](程序文件/docs/workspace-cleanup.md)。旧微信启动入口保留在`程序文件/legacy/启动公众号文章阅读器.cmd`，当前新构建的微信接口读取同一正式资料库。

维护和检查见[开发说明](程序文件/README.md)，MCP注册见[MCP配置](程序文件/docs/mcp-setup.md)，操作见[手册](程序文件/docs/link-library-manual.md)。应用不导入默认浏览器资料、不监听剪贴板，也不调用云端AI API。GitHub源码同步不等于用户资料备份。

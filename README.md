# 链接资料库

双击 [启动链接资料库.cmd](启动链接资料库.cmd)，粘贴链接或完整分享文案，点击“加入队列”再“开始保存”。应用会保存可取得的正文、图片和视频，并在本机生成音轨、字幕文字稿、语音转写、画面抽样、图片文字识别及离线阅读页/PDF。新资料保存在项目下的 `资料库/`。

首版接入微信公众号、小红书、B 站和普通网页。每条资料会区分已保存、部分保存、需要登录、缺少处理工具和失败。不同平台、账号和链接的实际验收范围见 [验收报告](程序文件/docs/link-library-acceptance.md)，不能据此推断所有链接均可下载。

资料库支持全文搜索、平台过滤、取消/重试、打开本地媒体和导出资料包。无平台字幕时使用本地语音模型；视频画面最多抽样 24 帧，机器识别结果有来源和时间点。首次缺工具时可点击“安装到应用目录”；模型和处理工具均保存在 `程序文件/` 中。

开发后在 `程序文件/` 运行 `cmd /c npm run build`。维护检查为 `cmd /c npm test`、`cmd /c npm run typecheck`，工具检查为 `node dist/link-cli.js doctor`。

## 原公众号窗口

原启动器和 `文章库/` 保留可用。新窗口首次读取资料库时复制兼容已有微信文章，不移动或删除原文件。

双击 [启动公众号文章阅读器.cmd](启动公众号文章阅读器.cmd)，粘贴微信公众号文章链接即可读取。每次读取会尝试保存 Markdown 正文、本地图片、可正常下载的视频和 PDF 到 `文章库/`，窗口分别说明各项结果。

选中文章后，可直接打开 Markdown、PDF 或本篇文件夹；视频文件在该篇的 `videos/` 目录中。双击文章条目打开 PDF。“重新生成 PDF”使用已保存的文章资料，不必重新读取网页。搜索支持标题和链接，“全部”恢复完整列表。

视频仅支持页面提供的可正常获取的微信/腾讯 HTTP(S) 视频直链，最多 20 段、每段 100 MB、总计 500 MB。受限、超限、过期或分段流视频会保留原文入口并说明未下载。Markdown 使用本地视频文件链接；PDF 保留视频说明与原文入口，不能在 PDF 内播放视频。

采集视频时会最多等待 15 秒，让微信播放器完成正常初始化及失败地址切换；不会把初始地址的一次 403 当成永久无法保存。下载会校验声明长度与完整响应范围，防止视频片段被误报为完整文件。重新读取同篇文章会保留已成功的视频并重试未保存的视频。

读取时窗口保持响应，可点击“取消读取”；已经保存的文件仍留在文章库。正文保存成功、部分图片或视频失败、PDF 失败会分别提示。错误日志可从窗口打开，位于 `程序文件/logs/reader.log`，只用于本地排错，不记录粘贴的链接或正文。

`程序文件/` 是应用的技术内容；日常不需要打开。阅读器只使用独立 Edge 会话，不读取默认浏览器资料或剪贴板。

需要本机安装 Node.js 与 Microsoft Edge；窗口兼容 Windows PowerShell 5.1。程序文件修改后，在 `程序文件/` 目录运行 `npm run build` 更新双击启动时使用的代码。维护检查为 `npm test` 和 `npm run typecheck`。
